# EmotiSense - Classroom Emotion Analytics

EmotiSense is a web application that uses computer vision and machine learning to analyze and track emotions in a classroom setting, providing real-time analytics to teachers and educators.

## Features

- Real-time emotion analysis for classroom sessions
- Department and section-based organization
- Beautiful, modern UI with responsive design
- Detailed analytics and insights for student engagement
- Supports multiple departments and classroom sections

## Technology Stack

- React with Vite for fast development
- Material UI and Tailwind CSS for styling
- Chart.js for data visualization
- React Router for navigation
- WebCam integration for live analysis

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Build for production with `npm run build`
